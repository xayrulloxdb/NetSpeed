# Интернет тезлиги (NetSpeed)

Samsung (ва бошқа Android 8+) телефонлар учун: статус-барда, соат ёнида ҳозирги интернет тезлигини кўрсатиб туради. Билдиришномалар панелида юклаб олиш (↓) ва юбориш (↑) тезлиги ҳамда жами трафик кўринади.

## APK'ни қандай олиш мумкин

### 1-йўл: GitHub орқали (компьютерга ҳеч нарса ўрнатмасдан)
1. github.com'да янги репозиторий очинг ва ушбу папкадаги барча файлларни юкланг (`.github` папкаси ҳам бўлиши шарт).
2. **Actions** бўлимига киринг — «Build APK» ўзи ишга тушади (тушмаса, «Run workflow» тугмасини босинг).
3. 3–5 дақиқадан кейин тугаган иш ичида **Artifacts → NetSpeed-apk** дан APK'ни юклаб олинг.

### 2-йўл: Android Studio орқали
1. Android Studio'ни ўрнатинг ва **File → Open** билан шу папкани очинг.
2. Gradle синхронлашуви тугашини кутинг.
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. Тайёр файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Телефонга ўрнатиш
1. APK'ни телефонга ўтказиб, очинг. Samsung «номаълум манбалардан ўрнатиш»га рухсат сўрайди — рухсат беринг.
2. Иловани очинг, билдиришномага рухсат беринг.
3. **«Батарея чекловини олиб ташлаш»** тугмасини босинг — Samsung бу бўлмаса фонда иловани ўчириб қўяди.
4. Қўшимча (тавсия): *Созламалар → Батарея → Фондаги чекловлар* ичида иловани «Ҳеч қачон ухламайдиган иловалар»га қўшинг.

## Эслатма
- Тезлик иконкаси статус-барда кўриниши учун билдиришномалар ёқилган бўлиши керак.
- Телефон қайта ёқилганда илова ўзи ишга тушади.
